# Cecilia Bazzucchi — Personal Portfolio & AI Hub

 Benvenuti nella repository ufficiale del mio sito web e portfolio personale ([ceciliabazzucchi.it](https://ceciliabazzucchi.it)).

Questo progetto rappresenta il mio hub digitale: una vCard interattiva e un portfolio Full-Stack che combina oltre **10 anni di esperienza nella gestione amministrativa/operations** con le mie nuove competenze evolute in **Web Development, AI Office Automation e Scripting**.

---

## 🌟 Features Principali

* **vCard & Interactive Resume:** Presentazione dinamica del mio profilo professionale, competenze ed esperienze lavorative (dalla gestione multi-societaria di 15 startup all'Office Management).
* **AI Chatbot Integrato:** Un assistente virtuale personalizzato integrato nella piattaforma, in grado di rispondere in tempo reale alle domande dei recruiter e dei visitatori sul mio percorso e sulle mie competenze.
* **Portfolio Progetti (Full-Stack & Automation):** Sezione dedicata alle soluzioni web sviluppate (es. *Mamedcare.it*), alle **Custom Gems** per la gestione documentale e alle web app in React/Node.js.
* **Responsive & Mobile-First Design:** Interfaccia ottimizzata per qualsiasi dispositivo (Desktop, Tablet, Smartphone) con tempi di caricamento ultra-rapidi.

---

## Tech Stack & Strumenti

### **Front-End & UI/UX**

* **Languages & Frameworks:** HTML5, CSS3, JavaScript (ES6+), React.js, Tailwind CSS
* **UI/UX:** Responsive Design, Micro-interazioni, Accessibility

### **Back-End & Database**

* **Environment:** Node.js, Express.js
* **Database:** SQL / Relational Databases

### **AI & Process Automation**

* **AI Integration:** Custom Gems (Google AI), Prompt Engineering, LLM Integration
* **Automation:** Python Scripting (compilazione ed elaborazione massiva di documenti)
* **Office Ecosystem:** Google Workspace, NetLex, Home Banking & Management Systems
